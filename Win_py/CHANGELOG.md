本项目的重要更改记录在此文件中。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循语义化版本。

## [1.1.8] - 2026-10-26

### 修复

- 修复「最小化到托盘」的系统通知不显示应用图标的问题。
  - Toast 模板新增 `<image placement="appLogoOverride">`，显式指定通知中的应用图标。
  - Windows 的 Toast 图片只支持 PNG/JPG/GIF 且无法加载含中文的路径，因此在发送前会把图标复制到临时目录并用哈希命名的纯 ASCII 路径引用。
  - 新增 96×96 的通知专用图标 `图标_通知.png`（14 KB），避免直接使用 2.5 MB 的大图被系统忽略。
- 开始菜单通知快捷方式已存在时，即使刷新属性失败（如目录只读）也不再降级为托盘气泡，直接沿用已有快捷方式。

### 变更

- 版本号升级至 1.1.8。

## [1.1.7] - 2026-10-26

### 修复

- 修复深色主题下文字「先变白、随后又变黑」的问题：原因是颜色设置后又用 `setStyleSheet("font-size…")` 覆盖了主题样式表。
  - 字号的设置改为 `QFont`，不再写样式表，避免覆盖主题文字颜色。
  - 状态文字（运行中/已停止）改为纯主题色文字，不再依赖容易被覆盖的背景样式。
- 覆盖范围：最近记录、设备总览、统计明细、管理页说明文字。

### 变更

- 版本号升级至 1.1.7。

## [1.1.4] - 2026-10-26

### 修复

- 修复 Windows 通知标题显示为 `Microsoft.Explorer.Notification.{...}` 的问题：
  - 新增「开始菜单快捷方式 + AppUserModelID」注册，使 Windows 能解析通知归属的应用名称。
  - 托盘最小化提示改用系统 Toast 通知（WinRT），标题正确显示为「运行时间跟踪器」。
  - WinRT 不可用时自动回退到托盘气泡，不影响功能。
- 通知正文改为「应用已最小化到系统托盘，可从托盘图标重新打开。」，提示更明确。

### 变更

- 新增依赖 `winrt-runtime`、`winrt-Windows.UI.Notifications`、`winrt-Windows.Data.Xml.Dom`。
- 构建时收集 `winrt` 子模块，保证打包后通知可用。
- 版本号升级至 1.1.4。

- 统计页优先读取服务端实际字段 `totalUsage / appStats / hourlyStats / appHourlyStats`，并兼容 Wiki 字段。

## [1.1.2] - 2026-10-26

## [1.1.1] - 2026-10-26

### 新增

- 应用映射页新增「打开配置文件」按钮，可用系统默认程序打开 `apps.json`；重新进入页面时会自动加载外部修改。
- 配置页新增「日志留存」设置：支持配置保留天数（1–3650）与保留数量（1–1000）。
- 历史日志自动清理：启动、保存配置及每 6 小时按配置删除超期或超量日志；当前日志永不删除，并兼容旧版 `runtime_tracker_YYYY-MM-DD.log` 命名。
- 新增日志留存相关单元测试。

### 修复

- 实测服务端管理接口实际挂载在 `/admin` 前缀下，客户端由根路径改为 `/admin/*`，修复管理页登录、配置、重启、AI 任务与账户接口 404。
- 管理登录失败返回 401 时不再误报为“登录已失效”，改为显示服务端返回的错误信息。
- 统计页适配服务端实际字段 `totalUsage / appStats / hourlyStats / appHourlyStats`，同时兼容 Wiki 文档字段；修复真实数据下总时长与应用列表显示为空的问题。
- 修复 `AI_MAX_TOKENS` 被误判为敏感字段而掩码、无法编辑的问题；只对真正的密钥类字段掩码。
- 修复后台托盘通知的应用标识：写入 exe 版本资源（FileDescription / ProductName 为“运行时间跟踪器”），并设置 AppUserModelID 与应用显示名，避免 Windows 通知显示 `Python` 或 `RunTimeTracker.exe`。
- 设备总览页电量值为 `0` 时显示为“—”，避免误显示为 0%。

### 变更

- 版本号升级至 1.1.1，并同步写入 exe 版本信息。
- 关于页 Tracker_Client 链接说明由“Android客户端”调整为“客户端”。
- 日志清理在读取配置前不会使用默认值提前删除日志，避免误删用户希望保留的历史日志。
- 构建流程增加 `version_info.txt` 版本资源。

## [1.1.0] - 2026-10-26

### 新增

- 项目由单文件 `main.py` 重构为 `app/`（核心逻辑）+ `ui/`（界面）+ 薄入口的分层结构。
- 新增统计页：今日 24 小时分布、应用排行、周维度统计（PyQtChart）。
- 新增最近记录页：设备最近 30 条应用切换记录。
- 新增设备总览页：所有设备的当前应用、运行状态、电量与更新时间。
- 新增服务器管理页：管理员登录、服务端配置查看/白名单修改、重启服务、AI 任务启停/手动触发、管理员账户更新。
- 新增设置页「测试连接」，通过 `GET /api/ip` 验证服务端可达性并显示延迟。
- 新增开机自启（HKCU Run）与 `--minimized` 托盘启动。
- 新增休眠、恢复、息屏、关机事件检测与状态上报。
- 新增应用映射自动保存、日志增量查看、日志导出与主题适配。

### 修复

- 补齐 `pywin32`、`PyQtChart` 依赖，修复干净环境启动 `ImportError`。
- 用户数据迁移至 `%APPDATA%\RunTimeTracker`，修复打包后 `apps.json` 修改重启丢失、配置写入只读目录失败的问题。
- 不再将 `config.json` 打入安装包，避免配置与密钥随包分发。
- 修复电池状态结构体使用有符号 `c_byte` 导致 `BatteryFlag=255/128` 判断错误的问题。
- 修复退出时强制 `terminate()` 监控线程、UI 线程同步重试最长阻塞约 17 秒的问题；网络上报与监控采集解耦。
- 上报修正：`batteryLevel` 仅发送 1–100；4xx 不重试；解析服务端 `error/details`；复用 `requests.Session`。
- 修复窗口标题识别规则重复两遍、单实例检测忽略托盘隐藏窗口、主题下拉初始化触发提前保存与弹窗等问题。
- 重写标题规则并修正 `apps.json` 中 Word 进程名、`ApplicationFrameHost.exe` 误映射等问题。

### 变更

- 管理接口 JWT 仅保存在内存，不写入配置、不写日志；非本机地址强制 HTTPS；敏感配置掩码且只读；破坏性操作二次确认。
- 日志改为按天轮转，默认保留 30 个历史文件。
- 版本号升级至 1.1.0，README 同步更新。

## [v1.0.1] - 2026-04-17

### 修复
- **FIX**: 修复应用映射界面"新增"按钮点击时闪退的问题
  - 原因: `dialog.textLayout` 属性不存在
  - 修复: 使用 `dialog.setFormContent()` 替代
- **FIX**: 修复应用映射界面"编辑"按钮点击时闪退的问题
  - 原因: `dialog.textLayout` 属性不存在 + `del` 操作可能抛出 KeyError
  - 修复: 使用 `dialog.setFormContent()` + `dict.pop()` 替代
- **FIX**: 修复应用映射界面"删除"按钮点击时闪退的问题
  - 原因: `del` 操作可能抛出 KeyError
  - 修复: 使用 `dict.pop()` 安全删除
- **FIX**: 修复保存应用映射时无法写入文件的问题
  - 原因: 使用 `get_resource_path()` 获取的路径在打包环境是只读的
  - 修复: 使用 `get_user_data_path()` 获取可写路径

### 变更
- 版本号从 1.0.0 更新至 1.0.1
- config.json 添加 version 字段
